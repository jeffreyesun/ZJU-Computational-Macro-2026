\section[nVFI]{神经价值函数迭代（Neural Value Function Iteration, nVFI）}
% =============================================================

\begin{frame}{神经价值函数迭代（neural Value Function Iteration, nVFI）}
  大致流程：
  \begin{enumerate}
    \item 用参数为 $\theta$ 的神经网络（neural network）对 $V^\text{end}(x^\text{end}, \Lambda^\text{start})$ 进行参数化
    \item （以某种方式）从 $\Lambda^\text{end}$ 抽样
    \item 对每个 $\Lambda^\text{end}$ 计算\textbf{外层贝尔曼残差}（outer Bellman residual，定义见下）
    \item 更新 $\theta$，从第 2 步起重复，直至收敛
  \end{enumerate}
\end{frame}

\begin{frame}{外层贝尔曼残差}
  考虑 Krusell-Smith 模型。

  设 $\Vendhat_\theta(x^\text{end}; \Lambda^\text{end}, Z)$ 为以 $\theta$ 为参数的神经网络。

  非正式地说，我们希望尽可能地满足
  \[
    \Vendhat_\theta(\xend; \Lstart, Z) - \E_{Z'}\psq{\Vstarthat\p{\xend; \Lstart{}', Z'}\mid Z} = 0,
  \]
  其中 $\Vstarthat(\xend;\Lstart{}',Z')$ 由先向前模拟、再向后迭代得到，所用的是 $\Vendhat_\theta, Z'$。
\end{frame}

\section[约定与时序]{约定与时序}

\begin{frame}{约定}
  \begin{enumerate}
    \item 家庭状态在家庭期之间不变：
    \[
      \xend_{it} = \xstart_{i,t+1},\quad\text{并且}\quad\Lend_{it} = \Lstart_{i,t+1}.
    \]
    \item 总量冲击发生在家庭期\textbf{之间}
    \begin{itemize}
      \item 即介于 $\Vend(\xend; \Lstart, Z)$ 与 $\Vstart(\xstart; \Lstart{}', Z')$ 之间
    \end{itemize}
    \item 仅依赖于\textbf{个体特异性}（idiosyncratic）状态的值函数\textbf{切片}（slice）或\textbf{猜测}（guess）以 tilde 表示，
    \[
      \Vstarttil(\xstart), \quad\text{而}\quad \Vstart(\xstart; \Lstart, Z).
    \]
  \end{enumerate}
\end{frame}

\begin{frame}{约定：对 $\Lstart$ 的依赖}
  \begin{itemize}
    \item 模型在家庭期内是确定性的。
    \item 因此，$\Lend$ 由 $\Lstart$ 唯一决定。
    \item 因此，\textbf{在理论上是有效的}：可以写 $\Vend(\xend; \Lstart, Z)$。
    \item \textbf{注意：}此处我\textbf{尚未}就如何在计算机上计算或表示 $\Vend$ 作出任何陈述！
  \end{itemize}
\end{frame}

\begin{frame}{约定：$\Vend$ 的偏应用}
  \begin{itemize}
    \item 如果我们对 $\Lstart$ 与 $Z$ 取条件，则 $\Vend$ 就只是 $\xstart$ 的函数。
    \item 即固定 $\Lstart$ 与 $Z$，可以定义
    \[
      \Vendtil(\xend) \equiv \Vend(\xend; \Lstart, Z).
    \]
    \item 用计算机科学的术语说，这是 $\Vend$ 在 $(\Lstart, Z)$ 处的\textbf{偏应用}（partial application）。
    \item 我们将其写成一个把\textbf{函数}映射到\textbf{函数}的算子
    \begin{align*}
      &\CV: (\Lstart, Z) \mapsto \Vendtil \\
      &\CV(\Lstart, Z)(\xend) \equiv \Vend(\xend; \Lstart, Z).
    \end{align*}
  \end{itemize}
  我的看法是：\textbf{延续价值算子}（continuation value operator）$\CV$ 是值函数在带总量冲击的异质性主体模型中的自然推广。
\end{frame}

\section[CVIAYN]{延续价值就是你所需要的一切（Continuation Value Is All You Need）}
% =============================================================

\begin{frame}{延续价值就是你所需要的一切}
  假设我们有一个模型，初始总量状态为 $(\Lstart, Z)$。

  再假设我们已经有延续价值算子 $\CV$。（这正是难的部分。）

  那么我们就可以将模型向前模拟：
  \begin{enumerate}
    \item $\Vendtil = \CV(\Lstart, Z)$
    \item $(\Vstarttil, \Lend) = \Phi(\Vendtil, \Lstart, Z)$
    \item 抽取 $Z' \sim \Pi(\cdot \mid Z)$
    \item $(\Lstart{}', Z') = (\Lend, Z')$
  \end{enumerate}
\end{frame}

\begin{frame}{回顾：典型的贝尔曼方程与算子}
  典型的贝尔曼方程通过下式定义 $V$：
  \[
    V(b, z) = \max_{c \in [0, b]} \; u(c) + \beta \, \E\!\left[\, V(b', z') \,\big|\, z \,\right]
  \]
  这可以视为贝尔曼算子 $\mathcal{T}$ 的不动点，该算子施行\textbf{前瞻}（lookahead）：
  \[
    \mathcal{T}v(b, z) \equiv \max_{c \in [0, b]} \; u(c) + \beta \, \E\!\left[\, v(b', z') \,\big|\, z \,\right]
  \]
  于是贝尔曼方程为
  \[
    V = \mathcal{T}V.
  \]
  下面我定义一个类似的\textbf{外层贝尔曼方程}。
\end{frame}

\begin{frame}{外层贝尔曼方程}
  真实的 $\CV$ 也满足一个递归方程，即\textbf{外层贝尔曼方程}：
  \[
    \Vend(\xend; \Lstart, Z) \;=\; \E_Z\psq{\Vstarttil{}'(\xend)\,\Big|\, Z},
  \]
  其中
  \begin{align*}
    \Vstarttil{}'  &= \Phi_V\bigl(\Lend, \Vendtil{}', Z'\bigr), \\
    \Vendtil{}' &= \CV(\Lambda^\text{end}, Z'), \\
    Z' &\sim \Pi_Z(\cdot \mid Z), \\
    \Lend &= \Phi_\Lambda(\Lstart, \Vendtil, Z), \\
    \Vendtil &= \CV(\Lstart, Z).
  \end{align*}
\end{frame}

\begin{frame}{外层贝尔曼算子}
  对任意 $\CV_\theta$，可以定义\textbf{外层贝尔曼算子}如下：
  \[
    \mathcal{L}\CV_\theta(\Lstart, Z)(\xend) \equiv \E_Z\psq{\Vstarttil{}'(\xend)\,\Big|\, Z},
  \]
  其中
  \begin{align*}
    \Vstarttil{}'  &= \Phi_V\bigl(\Lend, \Vendtil{}', Z'\bigr), \\
    \Vendtil{}' &= \CV_\theta(\Lambda^\text{end}, Z'), \\
    Z' &\sim \Pi_Z(\cdot \mid Z), \\
    \Lend &= \Phi_\Lambda(\Lstart, \Vendtil, Z), \\
    \Vendtil &= \CV_\theta(\Lstart, Z).
  \end{align*}
\end{frame}

\begin{frame}{外层贝尔曼残差}
  真实的\textbf{延续价值算子} $\CV$ 由下式定义：
  \[
    \mathcal{L}\CV = \CV.
  \]
  对任意 $\CV_\theta$，可以定义\textbf{外层贝尔曼残差}为
  \[
    \mathcal{L}\CV_\theta - \CV_\theta,
  \]
  并将逼近 $\CV$ 的问题写成
  \[
    \min_\theta \norm{\mathcal{L}\CV_\theta - \CV_\theta}^2.
  \]
\end{frame}

\begin{frame}{从第七讲继承的内容}

第七讲的 K-S 笔记本已经为我们提供了除网络与训练循环之外的一切：

\begin{itemize}
  \item \texttt{KSParams}（第七讲第 3 节）。
  \item \texttt{ks\_prices(K, Z, p)}（第七讲第 4 节）。
  \item 三阶段\emph{模拟}链 \texttt{ks\_household\_sim} = \texttt{z\_shock} $\circ$ \texttt{income} $\circ$ \texttt{savings}（第七讲第 8 节）。
  \item \texttt{aiyagari\_steady\_state\_at\_Z}（第七讲第 5 节）——为预训练给出 $V_{\mathrm{ss}}$，并提供采样器的初始条件 $\Lambda_{\mathrm{ss}}$。
\end{itemize}

\smallskip

\textbf{我们舍弃的部分：}\texttt{K\_evolve} + \texttt{Z\_shock} 链的尾段（即家庭对总量运动法则 ALM 的信念），\emph{以及}$V$ 中的 $K$-网格。网络取代了这两者。

\end{frame}

\begin{frame}{$\Phi$ 在代码中：就是那条模拟链}

三阶段链\emph{就是}我们的 $\Phi$。给定个体特异性 $(b, z)$ 网格上的任意 $\Vendtil$，它

\begin{itemize}
  \item 向后运行得到 $\Vstarttil$（savings 阶段求解家庭的选择；income / z\_shock 阶段组合而成）；
  \item 向前运行，将 $\mu^\text{start}$ 推到 $\mu^\text{end}$。
\end{itemize}

\smallskip

它单独无法做到的唯一一件事，是提供 $\Vendtil$。这正是 $\CV_\theta$ 所提供的。

\end{frame}

\begin{frame}{网络结构：$\Lambda$ 如何进入？}

我们不能把一个 $N_b \times N_z$ 的场直接塞进一个全连接层而指望学到什么。标准做法（Han--Yang--E 2025）是：在 value head 看到 $\Lambda$ 之前，先把它总结为一个小的\emph{可学习}向量。

\smallskip

四个子网络：
\begin{enumerate}
  \item \texttt{pop\_agg\_net} $: (b, z) \to \R^{k}$ —— 对每个 cell 做嵌入。
  \item $\mathrm{GM}(\Lambda) = \sum_{(b,z)} \Lambda(b, z) \cdot \texttt{pop\_agg\_net}(b, z) \in \R^k$ —— 嵌入的人口加权均值。一次矩阵乘法。
  \item \texttt{V\_pre} $: (b, z) \to \R^m$ —— value head 用到的 cell 级特征。
  \item \texttt{V\_post} $: \R^{m + N_Z} \to \R$ —— 将 \texttt{V\_pre} 的特征、（投影后的）GM 与 $Z$ 的 one-hot 相组合。
\end{enumerate}

\smallskip

组合方式是\textbf{加法的}：\texttt{V\_pre(cell) + gm\_post(GM)}，然后再拼接 $Z$。

\end{frame}

\begin{frame}[fragile]{网络在代码中的样子}
\begin{lstlisting}
struct VNet{A, P, G, V}
    pop_agg_net::A   # 2 -> gm_dim       per-cell embedding
    V_pre::P         # 2 -> mid          per-cell features
    gm_post::G       # gm_dim -> mid     project GM to mid
    V_post::V        # mid + N_Z -> 1    combine + Z
end

function (net::VNet)(Λ, Z_idx, p)
    pop_emb = net.pop_agg_net(HH_FEAT)       # (gm_dim, N_cells)
    gm      = pop_emb * Float32.(vec(Λ))     # (gm_dim,)
    h       = net.V_pre(HH_FEAT) .+ net.gm_post(gm)  # (mid, N_cells)
    pred    = net.V_post(vcat(h, Z_ROWS[Z_idx]))     # (1, N_cells)
    return reshape(pred, p.N_w, length(p.z_grid))
end
\end{lstlisting}

瓶颈 $k = $ \texttt{gm\_dim} 用一个可学习的 $k$ 维摘要替换了 $N_b N_z$ 维的输入。

\end{frame}

\begin{frame}[fragile]{在 $V_\theta$ 下进行一次内层求解}
\begin{lstlisting}
function inner_solve(hh, vnet::VNet, Λ::AbstractMatrix, Z_idx::Int, p)
    V_end = Float64.(vnet(Λ, Z_idx, p))   # N_b x N_z
    env   = make_env(hh; ks_prices(integrate_K(hh, Λ),
                                   p.Z_vals[Z_idx], p)...)
    return backward!(hh, V_end, env)
end
\end{lstlisting}

\vspace{0.4em}

\begin{itemize}
  \item 网络在 $(\Lambda, Z)$ 处预测 $\Vendhat_\theta$。
  \item 以价格 $(r, w) = \texttt{ks\_prices}(K(\Lambda), Z, p)$ 构造 \texttt{env}。价格仅通过 $K = \int b\, d\Lambda$ 依赖于 $\Lambda$ ——这是生产技术的设定，而非网络架构的特性。
  \item 在三阶段链上做一次向后扫掠 $\Rightarrow$ $\Vstarttil$。
\end{itemize}

\end{frame}

\begin{frame}[fragile]{前瞻算子 $\Lop V_\theta$}
\begin{lstlisting}
function lookahead(hh, vnet, Λ_start, Z_idx, p)
    # Forward one period under V_theta to get Lambda_end.
    V_end_now = Float64.(vnet(Λ_start, Z_idx, p))
    env_now   = make_env(hh; ks_prices(integrate_K(hh, Λ_start),
                                       p.Z_vals[Z_idx], p)...)
    backward!(hh, V_end_now, env_now)
    Λ_end = forward!(hh, Λ_start)

    # Backward at each next-period Z; take expectation over Z.
    V_end_pred = zeros(p.N_w, length(p.z_grid))
    for Z_next in 1:N_Z
        V_start_next = inner_solve(hh, vnet, Λ_end, Z_next, p)
        V_end_pred .+= p.P_Z[Z_idx, Z_next] .* V_start_next
    end
    return V_end_pred
end
\end{lstlisting}
\end{frame}

\begin{frame}{刚才发生了什么}

我们在一个样本 $\Lstart_i$（总量索引为 $Z_i$）处计算了 $\Lop V_\theta$：
\begin{enumerate}
  \item 网络在 $(\Lstart_i, Z_i)$ 处预测 $\Vendhat_\theta$。
  \item $\Phi$ 把 $\Lstart_i$ 向前推一步 $\to$ $\Lambda^\text{end}_i$。
  \item 对每个 $Z_\text{next}$，网络在 $(\Lambda^\text{end}_i, Z_\text{next})$ 处预测 $\Vendhat_\theta$。经过 $\Phi$ 的向后扫掠得到 $\Vstart_\text{next}$。
  \item 用 $P_Z[Z_i, \cdot]$ 对 $Z_\text{next}$ 取期望。
\end{enumerate}

\smallskip

结果是一个 $(b, z)$ 形状的数组 $\widehat\Vend_i$。这就是我们的训练标签。

\end{frame}

\begin{frame}[fragile]{训练损失}
\begin{lstlisting}
function bellman_residual_loss(vnet, batch, p, hh)
    L = 0.0
    for (Λ_start, Z_idx) in batch
        target = lookahead(hh, vnet, Λ_start, Z_idx, p)
        pred   = vnet(Λ_start, Z_idx, p)
        L += mean((pred .- Float32.(target)).^2) / var_scale(target)
    end
    return L / length(batch)
end
\end{lstlisting}

\vspace{0.4em}

\textbf{对标签使用 stop-gradient。}前瞻只算一次，并作为固定的目标处理。我们\emph{不}对 $\Phi$（期内求解器）做反向传播。只有 $V_\theta$ 直接对 $\theta$ 的依赖才进入梯度。

\end{frame}

\begin{frame}[fragile]{对 $\Lstart$ 的采样}
\begin{lstlisting}
function sample_ergodic(hh, vnet, p; T=200, burn=100, every=2, rng=...)
    Λ, Z_idx = copy(Λ_ss), 1
    batch = Tuple{Matrix{Float64}, Int}[]
    for t in 1:T
        V_end = Float64.(vnet(Λ, Z_idx, p))
        env   = make_env(hh; ks_prices(integrate_K(hh, Λ),
                                       p.Z_vals[Z_idx], p)...)
        backward!(hh, V_end, env); Λ = forward!(hh, Λ)
        Z_idx = sample_Z(Z_idx, p.P_Z, rng)
        t > burn && (t - burn) % every == 0 && push!(batch, (copy(Λ), Z_idx))
    end
    return batch
end
\end{lstlisting}

MCMC 风格：在\emph{当前}的 $V_\theta$ 下进行模拟，烧入（burn in），然后子采样。

\end{frame}

\begin{frame}[fragile]{训练循环}
\begin{lstlisting}
function train!(vnet, p, hh; epochs=50, lr=1e-3, batch_kwargs=(; T=200, burn=100))
    opt  = Flux.setup(Adam(lr), vnet)
    hist = Float64[]
    for epoch in 1:epochs
        batch = sample_ergodic(p, hh, vnet; batch_kwargs...)
        loss, grads = Flux.withgradient(vnet) do net
            bellman_residual_loss(net, batch, p, hh)
        end
        Flux.update!(opt, vnet, grads[1])
        push!(hist, loss)
    end
    return hist
end
\end{lstlisting}
\end{frame}

\begin{frame}{初始化很关键}

随机初始化的 $V_\theta$ 通常会让期内求解失败（如出现数值上无界的消费等）。

\smallskip

\textbf{预训练。}让网络在一个 $\Lambda$ 的云（对 $\Lambda_{\mathrm{ss}}$ 加扰动）以及所有 $Z$ 上去拟合确定性的值函数 $V_{\mathrm{ss}}$。这\emph{不是}因为 $V_{\mathrm{ss}}$ 在任何 $\Lambda \neq \Lambda_{\mathrm{ss}}$ 处是正确的——它并不正确——而是因为它是一个合理的\emph{常数基线}，能在残差训练循环开始挪动一切之前，把 $V_\theta$ 调到合适的量级与形状。

\smallskip

成本低，不依赖第七讲。

\end{frame}

\begin{frame}[fragile]{运行}
\begin{lstlisting}
p    = KSParams()
hh   = ks_household_2d(p)
vnet = VNet()
pretrain_to_ss!(vnet, V_ss, p)

hist = train!(vnet, hh, p; epochs=50)
plot(hist; yaxis=:log, lw=2,
     xlabel="epoch", ylabel="outer Bellman residual")
\end{lstlisting}

\vspace{0.4em}

\textbf{诚实声明。}CPU 上 50 个 epoch 只是\emph{演示}，而非已收敛的解。真实的运行需要在 GPU 上跑数千乃至上万个 epoch。详见第 7 节。

\end{frame}

% =============================================================
\section[解读结果]{解读结果}
% =============================================================

\begin{frame}{训练曲线}

\begin{itemize}
  \item 外层贝尔曼残差（对数尺度）随训练 epoch 的变化。
  \item 应当看到一条带噪声但总体下降的曲线。
  \item 在真实运行中（Peking 2025 deck 第 5 节）：神经网络达到约 $10^{-4.4}$ 的相对方差；K-S 基线则在约 $10^{-3.2}$ 处停滞。
\end{itemize}

\smallskip

差距才是要点：收敛后，在同一问题上，$V_\theta$ 对残差方差的解释\emph{优于} K-S，而且无需任何参数化先验形式。

\end{frame}

\begin{frame}{“外层贝尔曼残差”作为误差意味着什么}

残差小意味着 $V_\theta$ 近似是 $\Lop$ 的不动点。

\smallskip

由压缩映射论证（标准结果，当 $\Lop$ 是 $\beta$-压缩时成立），这意味着 $\norm{V_\theta - V} \leq \frac{1}{1-\beta}\norm{V_\theta - \Lop V_\theta}$。残差小 $\Rightarrow$ 离真值近。

\smallskip

\textbf{警示。}对本设定而言，$\Lop$ 的压缩性质属于研究层面的问题；论文附录给出了一些条件。对我们的 K-S 基线而言，经验上的压缩性是成立的。

\end{frame}

\begin{frame}{与 K--S 的比较}

将 $V_\theta$ 与第七讲的 K-S 基线进行比较，有三种方式：
\begin{enumerate}
  \item \textbf{值函数 MSE}：在共同的 $(b, z, \Lambda_t, Z_t)$ 模拟路径上比较。K-S 在 $K_t$ 处取值；CVIAYN 在 $\Lambda_t$ 处取值。
  \item \textbf{策略 MSE}：从二者分别抽取 $b'$，再做比较。
  \item \textbf{Den Haan 误差}：分别在两种方法下模拟总量 $K_t$ 路径。在此基线校准下，CVIAYN 与 K-S 在该指标上仅相差噪声，这是因为 K-S 的\emph{先验形式}（ansatz）恰好在该基线校准下接近真实情况（见第七讲第 6 节）。
\end{enumerate}

\smallskip

有意思的差距出现在 (1) 与 (2)，并集中在尾部状态（罕见的 $\Lambda$、罕见的 $Z$）上：K-S 外推的是线性 ALM；CVIAYN 外推的是网络。

\end{frame}

\begin{frame}{K--S 等价性在何处崩溃}

K--S \emph{在基线校准下}看上去与 CVIAYN 难以区分。这是因为 $K$ 的条件运动法则恰好近似对数线性——而且我们为定价所关心的人口边际分布 $K$ 恰好是一个标量。

\smallskip

\textbf{CVIAYN 拉开差距的场景}：

\begin{itemize}
  \item 多资产（流动性差的财富）：动态不再是对数线性。
  \item 离散选择（行业、职业）：占有份额不是 $K$ 的矩。
  \item 空间模型：\emph{跨}地区的分布无法由总量来概括。
\end{itemize}

在以上每一种情形中，K--S 都需要一个手工构造的、追踪额外矩的先验形式；CVIAYN 只需扩展 GM 的输入。

\end{frame}

\section[推广]{推广}
% =============================================================

\begin{frame}{这在哪里重要}

\textbf{标量 $K$ 先验形式\emph{无法}奏效的模型：}

\begin{itemize}
  \item 搜寻--匹配（vacancy distribution）。
  \item OLG（横截面的年龄结构）。
  \item 空间模型（人口在何处，而非仅仅有多少）。
  \item 多资产（流动性 vs.\ 流动性差的构成）。
  \item 离散选择（职业构成）。
\end{itemize}

\smallskip

带 GM 输入的 CVIAYN 可以推广到所有这些情形而不改动算法本身。配方沿着良好理解的轴线扩展：更多的 cell 特征、按地区的 GM、按年龄的 GM。

\end{frame}

\begin{frame}{GM 架构如何扩展}

\textbf{按地区的 GM（空间/城市模型）。}对每个地区 $\ell$ 用其自身的 $\Lambda$ 切片构造一个 $\mathrm{GM}_\ell$。再用一个“聚合的聚合”（aggregate-of-aggregates）网络在地区之间做汇总。

\smallskip

\textbf{年龄分层（OLG）。}对每个队列（cohort）运行一个独立的 \texttt{pop\_agg\_net}，或者共享权重，把年龄作为额外的 cell 特征喂入。

\smallskip

\textbf{多资产。}状态空间增加一个维度；\texttt{pop\_agg\_net} 的输入变为 $(b_{\mathrm{liq}}, b_{\mathrm{illiq}}, z)$。其余不变。

\smallskip

\textbf{非人口状态。}另启一个 \texttt{env\_net}，把外生总量状态嵌入一个并行的 GM；按同样的方式加到 cell 级特征上。

\end{frame}

\begin{frame}{优化后的参考实现}

笔记本中的训练循环虽诚实，但属于教学版本。一个生产级别的实现位于本仓库中：

\begin{itemize}
  \item \texttt{reference\_materials/}\\\texttt{example\_usage/stochastic\_transition/code/}\\\texttt{stochastic\_transition/}
\end{itemize}

\smallskip

它在今天的结构之上还增加了：按地区的 GM + 聚合的聚合 head；用于非人口状态的并行 env\_net；余弦退火学习率；低显存的梯度累积；模拟路径上对期内求解的缓存；按地区的反向传播配以共享的 GM。

\smallskip

\emph{算法}本身没变，新增的全是工程化的管线（plumbing）。

\end{frame}

\begin{frame}{单步前瞻只是一个旋钮}

第 5 节中的前瞻是单期的：在 $\Lstart$ 处求解 $\Phi$，抽取 $Z_\text{next}$，在 $\Lstart{}'$ 处再次求解 $\Phi$，然后取期望。

\smallskip

\textbf{$n$ 步前瞻。}在算子内部做 $n$ 轮 $(\Phi, \Omega)$。等价于施加 $\Lop^n$。

\smallskip

\begin{itemize}
  \item 优点：残差目标的偏差更小（前瞻越深 $\to$ 标签越真）。
  \item 缺点：成本随 $n$ 线性增长；方差随 $Z$ 路径数增长。
\end{itemize}

笔记本中使用 $n = 1$。改成更高的 $n$ 只需一行修改。

\end{frame}

\begin{frame}{时序约定为何重要}

将值函数拆分为 $\Vstart$ 与 $\Vend$ 是让 $\CV$ 成为一个干净对象的关键。

\smallskip

\textbf{若不做拆分：}$V(\xstart, \Lstart)$ 依赖于 $\Lstart$，同时也隐含地对 $t$ 期\emph{内}发生的一切进行预报。这使得“网络学到了什么”与“$\Phi$ 计算了什么”难以分离。

\smallskip

\textbf{做拆分之后：}$\Vend$ 位于下一次总量冲击\emph{之前}那一刻。期内的一切由 $\Phi$ 处理；跨期的一切由 $\CV$ 处理。

\end{frame}

\begin{frame}{为何对标签使用 stop-gradient}

标签 $\widehat\Vend_i$ 本身就是用 $V_\theta$（通过前瞻）算出来的。也可以对其反向传播。

\smallskip

\textbf{我们不这样做的理由：}

\begin{itemize}
  \item 每次前瞻包含数次 $\Phi$ 的运行，而 $\Phi$ 中涉及网格搜索、单调搜索技巧以及其他不可微的环节。
  \item “损失即不动点残差”这一表述是 ML 处理价值迭代的标准做法；SARSA、Q-learning 等都对 bootstrap 目标做停止梯度（stop gradient）。
  \item 经验上，半梯度（semi-gradient）能稳定训练。
\end{itemize}

\end{frame}
